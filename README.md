# Adaptive Land Prep

Mobile-first 56-week adaptive land-preparation PWA.

Personal readiness, HRV, weight and workout records are stored on the user's device, not in this public repository. The app includes IndexedDB-backed local persistence plus JSON backup/restore.

## iPhone installation
Once GitHub Pages is enabled for the `main` branch/root folder, open the HTTPS Pages address in Safari and choose **Share → Add to Home Screen**.
