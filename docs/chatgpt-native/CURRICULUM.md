# Authoritative BUD/S Land-Prep Curriculum

Preserved from the final Adaptive Land Prep repository. This is a land-preparation curriculum, not a complete BUD/S program or medical protocol.

## Macro phases
| Phase | Weeks | Objective |
|---|---:|---|
| Foundation | 1–16 | Lose excess body fat, rebuild aerobic base, establish strength consistency, prepare tissues for impact. |
| Engine + Load | 17–32 | Build running speed, threshold capacity and loaded-walking durability. |
| Specificity | 33–44 | Shift toward selection-specific running, bodyweight performance and loaded movement. |
| Peak Work Capacity | 45–52 | Demonstrate high accumulated workload without localized bone pain or mechanical breakdown. |
| Taper | 53–56 | Dissipate fatigue, retain key qualities and arrive healthy. |

## Strength anchors
Session A: back squat 3×5; RDL 3×6–8; overhead press 3×5; pull-ups 3–5 submax sets; tibialis 3×15–25; calf/soleus 3×12–20; neck harness 2–3 controlled sets each direction; grip 2–3 sets.
Session B: split squat/reverse lunge 3×6–8/leg; hip hinge 3×6–8; press + row 3×6–10 each; suitcase carry 3×40–100 m/side; tibialis + soleus 3 sets; neck harness 2–3 sets; forearm roller 2–3 climbs.

## Session-construction rules
- Easy row: 5–10 min warm-up, 40–75 min conversational main work, 5 min cool-down.
- Recovery aerobic: 25–60 min very easy; finish better than started.
- Row threshold/quality run: only with current established calibration. Otherwise use conversational Concept2 work rather than invented intensity.
- Intro run/walk: 5–10 min walk, 10–25 min easy run/walk, 5 min walk; stop for focal pain or altered gait.
- Easy run: conversational, no speed chasing.
- Quality run: 15–20 min warm-up, calibrated main work only, 10–15 min cool-down.
- Medium run: below threshold and controlled.
- Long/ruck: increase distance before pack load; preserve normal gait.
- Taper strength: about 60–70% of normal training load; no failure/soreness-seeking.

## Phase-promotion gates
Foundation: >=7 check-ins, >=8 strength sessions, >=8 aerobic sessions, >=14 complete days. No body-fat percentage is an automatic promotion lock.

Engine + Load set 1: >=28 complete days, >=12 loaded sessions, >=16 aerobic sessions, no unresolved curriculum debt.
Set 2: 4 mi <24:00; 12 mi with 30 lb; loaded walking comfortable; phase mastery >=75%.

Specificity set 1: >=80 strict push-ups, >=15 strict pull-ups, >=70 sit-ups, mastery >=75%.
Set 2: >=100 strict push-ups, >=20 strict pull-ups, >=90 sit-ups, 4 mi <=22:00.

Peak Work Capacity set 1: >=14 complete phase days, >=8 loaded/endurance sessions, mastery >=75%, no unresolved debt.
Set 2: peak simulation pain-free, >=100 push-ups, >=20 pull-ups, 4 mi <=22:00.

Taper: >=14 complete taper days; no unresolved debt; peak durability pain-free; maintain 4 mi <=22:00 + >=100 push-ups + >=20 pull-ups; mechanical check-in clear; nutrition day complete; final check-in complete; program mastery >=80%.

## Accounting
A complete day requires a check-in plus completed workout on the same task date. Failed days count against mastery. Partial work contributes to weekly actual volume but not completed-day mastery. Calendar time alone does not guarantee progression.

## Scope
Swimming is intentionally excluded from this 56-week land curriculum. Add any swim program as a separate coordinated track rather than silently changing land-load progression.
